How Squads Work

SEC // Squads
01

Captain Creates

The captain creates the squad and gets its join code.

02

Share the Code

The captain shares the join code with the players who will join.

03

Members Join

Players join with the code. A squad holds 4 to 5 players.

04

Apply Together

With at least 4 members, the squad applies for tournaments and the admin assigns squads.
